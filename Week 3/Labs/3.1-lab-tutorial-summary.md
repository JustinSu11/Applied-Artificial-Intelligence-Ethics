**One line:** Measure bias in the data, train a model, then
compare **Original vs Reweighing vs DIR** on both fairness and
performance. Fairness gains cost a little accuracy.

## Setup
- **Dataset:** adapted Taiwan credit card default data,
  **30,000 clients**, file `credit_card_default_531v.1.csv`.
- **Target:** `default payment next month` renamed
  `DEFAULT_NEXT_MONTH` (1 = default, 0 = no default).
  **Favorable label = 0** (no default).
- **SEX** recoded: 1 = male, 0 = female.
- **Features kept:** LIMIT_BAL, SEX, EDUCATION, MARRIAGE, AGE.
- **Protected attribute:** age, as `Age_Group`.
  - **Privileged = 26-47** (1)
  - **Unprivileged = 21-25 and 48+** (0)
- **Seed 531.** Train/test split **75/25.**
- **Libraries:** aif360, lightgbm, scikit-learn, tqdm, seaborn,
  pandas. **DIR also needs BlackBoxAuditing.**
- **Model:** `LGBMClassifier(learning_rate=0.4, reg_alpha=21,
  reg_lambda=1, scale_pos_weight=1.8, max_depth=6,
  num_leaves=33)`.
- **Wrapper:** `BinaryLabelDataset` (AIF360's data container).
- **Caveat:** cell 4's `read_csv` path is a placeholder
  (`r"........credit_card_default_531version.csv"`). Fix it to
  your real path.

## Step 1: bias in the training data (before any model)
| Metric | Value | Reading |
|---|---|---|
| **SPD** | **-0.1202** | Negative = unfair to the unprivileged |
| **DI** | **0.8480** | Below 1 = unfavorable to the unprivileged. Above 0.8, so it passes the four-fifths rule |
| **SEDF** | **0.8774** | Far from 0 = not fully fair |

## Step 2: baseline model (Original)

- Test fairness (Original): **SPD -0.1385, DI 0.8339,

## Step 3: Reweighing (pre-processing)
- Reweights samples by group and label. **Features and labels
  unchanged.**
- **Training data after:** SPD **-0.0000**, DI **1.0000**,
  SEDF **0.7310.**
- **Test performance:** acc **0.8057**, precision **0.6140**,
  recall **0.5360**, F1 **0.5724**, ROC-AUC **0.7908.**
- **Test fairness:** SPD **-0.0541**, DI **0.9326**, EOD
  **0.0318**, AOD **-0.0133**, DFBA **0.1209.**
- Cost: accuracy down about **1 point.**

## Step 4: Disparate Impact Remover (pre-processing)
- **Repair level** = how much the features are edited
  (0 = none, 1 = full repair).
- The protected attribute (`Age_Group`) is **dropped from the
  features** before training, so the model can't use it directly.
- Loop over levels, train at each, keep the one with the best
  DI: `levels = np.hstack([np.linspace(0.,0.1,41),
  np.linspace(0.2,1,9)])`.
- **Best repair level = 0.40, DI = 0.8683.**
- **Test performance:** acc **0.8109**, precision **0.6281**,
  recall **0.5404**, F1 **0.5810**, ROC-AUC **0.7949.**
- **Test fairness:** SPD **-0.1078**, DI **0.8683**, EOD
  **-0.0170**, AOD **-0.0699**, DFBA **0.1588.**

## Step 5: side-by-side (test set)
| Metric | Original | Reweighed | DIR |
|---|---|---|---|
| **SPD** | -0.1385 | **-0.0541** | -0.1078 |
| **DI** | 0.8339 | **0.9326** | 0.8683 |
| **SEDF** | 0.9115 | **0.7310** | 0.9115 |
| Accuracy | **0.8176** | 0.8057 | 0.8109 |
| ROC-AUC | **0.7991** | 0.7908 | 0.7949 |

**Takeaway:** Reweighing gives the **biggest fairness gain**
(SPD and DI nearly fixed) for about a **1-point accuracy drop.**
DIR helps less here. This is the **fairness-accuracy trade-off**
in numbers.

# LAYER 1: LEARN IT

## The big idea
Two jobs: (1) **build** a normal classifier, (2) **open it up**
with SHAP. The model is boring on purpose (logistic
regression). The point is reading the plots.

**Hook:** the model is a **judge**, SHAP is the **court
transcript** of which facts swayed the verdict.

## The data
- **Adult / Census Income** dataset, from the **1994 US Census
  Bureau** database.
- Task: classify income **above or below $50,000** a year.
- Features: age, work class, education level, marital status,
  occupation, race, gender (Sex), hours worked, and more.
- Used for classification and explainable AI demos.

## Step-by-step (code, in notebook order)
| # | Step | What it does |
|---|------|--------------|
| 1 | `X, y = shap.datasets.adult()` | load data |
| 2 | `train_test_split(..., test_size=0.2, random_state=1)` | **80/20** split |
| 3 | `cats` and `nums` lists | split columns by type |
| 4 | `ColumnTransformer` | one-hot encode **cats**, standardize **nums** |
| 5 | `Pipeline([preprocessor, LogisticRegression(max_iter=10000)])` | one object: prep + model |
| 6 | `model.fit(X_train, y_train)` | train |
| 7 | `X_sub = shap.sample(X_train, 100)` | **background** sample of 100 training rows |
| 8 | `ex = shap.Explainer(model.predict_proba, X_sub)` | explain the **probability** output |
| 9 | `shap_values = ex(X_test.iloc[0:100])` | SHAP values for the **first 100 test rows** |

- **cats:** Workclass, Marital Status, Occupation,
  Relationship, Race, Sex, Country.
- **nums:** Age, Education-Num, Capital Gain, Capital Loss,
  Hours per week.
- **OneHotEncoder** = turns categories into 0/1 columns.
- **StandardScaler** = puts numbers on the same scale.
- **Background sample** = the "average person" SHAP compares
  against. Gives the **base value** (starting point).
- `shap_values` shape = (rows, features, classes) so we index
  `[row, :, class]`.

**Indexes used**
- `class_index = 1` -> **> $50K**. `0` -> **<= $50K**.
- `data_index = 0` -> the **first** test instance (zero-based).

## Plot 1: Bar plot (one person)
`shap.plots.bar(shap_values[data_index,:,class_index])`
- **Length** = size of the push.
- **Blue** = pushes probability **down.** **Red** = **up.**
- Sorted by size.

**Lecture reading (instance 0):** Education **-0.09** (largest
negative); Occupation and Marital Status large negative; Sex
smaller negative (**-0.04**); **Hours per week +0.04**
(largest positive); Age also pushes up.

**Trap:** this bar plot is **local** (one person). Don't read
it as "what the whole model cares about" (that's beeswarm).

## Plot 2: Force plot (one person, direction)
`shap.initjs()` first (loads the JavaScript), then
`shap.plots.force(shap_values[data_index,:,class_index])`.
- Starts at the **base value** (average predicted probability),
  **about 0.22** = about 22% chance of ">50K".
- Red features push right (higher); blue push left (lower).
- Age and Hours per week push up a little; Education,
  Occupation, Marital Status, Sex push down harder.
- Ends at the model's **final prediction** for that person.

**Hook:** a **tug-of-war** starting at 22%. Blue wins by a lot.

## Plot 3: Beeswarm (whole model)
`shap.plots.beeswarm(shap_values[:,:,class_index])`
- **Rows** = features, sorted by importance (top = most).
- **X-axis** = SHAP value. **Left (negative)** pushes toward
  the lower class; **right (positive)** pushes toward ">50K".
- **Dots** = one per person. **Color:** **red = high feature
  value, blue = low.** (Age: blue = younger, red = older.)
- Gives three things: **importance, direction, value pattern.**

**Lecture readings**
- **Marital status:** wide spread; categories differ (some
  raise, some lower).
- **Capital gain:** big spread; **high (red)** -> strongly
  **positive**; low (blue) -> little or no impact.
- **Sex:** blue points mostly push the prediction **lower**;
  red cluster near neutral or positive. *(The lecture doesn't
  say which code is male or female. Dataset values are 0 and 1.)*

# MY ADDITIONS: things I checked running the code

**Ran on latest libraries (shap 0.54.1, scikit-learn 1.9.1,
pandas 3.0.5): works, no pinning needed.**
The explainer used was `PermutationExplainer`. Efficiency held:
max gap between (base + sum of SHAP) and the model probability
was about 5e-8 across the 100 rows.

**Global top features by mean |SHAP| (class 1, 100 rows):**
Marital Status 0.105, Education-Num 0.061, Capital Gain 0.053,
Occupation 0.048, Sex 0.029, Age 0.025.

**Bug to know about (a latent one):** `OneHotEncoder()` with the
default `handle_unknown='error'` crashes if the test set has a
category not seen in training. Country value **15** appears
**once in the whole data and lands in the test set** (not in the
first 100 rows). So `model.score(X_test, y_test)` crashes with
*"Found unknown categories [15] in column 6"*, while the lab's
first-100-rows SHAP run works. Fix: 
`OneHotEncoder(handle_unknown='ignore')`. With it, test
accuracy = **0.8524** (vs 0.7717 for always guessing <=$50K).

`shap.sample` defaults to `random_state=0`, so the 100 background
rows are repeatable.

**One line:** **SHAP** splits a model's prediction into one number
per feature ("how much did this feature push the answer?"),
using a fair-sharing rule from game theory (**Shapley values**).
It works on **any** model. It shows bias but **doesn't fix** it.

**Where it fits:** 5.1 defined explainability. SHAP is the
standard tool for it. The lab (lab 5.2) uses it on real data.

# LAYER 1: LEARN IT

## The big idea
A model says "92% chance of X". Why? SHAP answers with a
**scoreboard:** each feature gets credit (+) or blame (-), and
the credits add up to exactly how far the prediction moved from
the average.

**Hook:** a **group dinner bill.** The total is the prediction.
SHAP is the fair rule for who owes what.

## 1) Model interpretability, and why ethics cares
**Problem:** black boxes can't be trusted or checked.
- **Model interpretability** = how much a human can understand
  the **cause** of a model's decision or prediction.
- Ties to three ethics ideas:
  - **Fairness:** no unfair bias on sensitive attributes
    (race, gender, socioeconomic status).
  - **Accountability:** developers, regulators, users can hold
    AI responsible, vital in **criminal justice, healthcare.**
  - **Transparency:** decision process clear so people can
    trust it.

## 2) What SHAP is
- **SHAP** = **SH**apley **A**dditive ex**P**lanations (Python
  library).
- Built on **Shapley values** from **cooperative game theory:**
  players team up for a payout; Shapley value = each player's
  fair share of the total.
- In ML: **feature = player, prediction = payout.**
- It tests **all possible combinations of features** to see
  what each one adds.

**Model-agnostic:** works on linear/logistic regression,
decision trees, neural networks, anything.

**Local vs global**
| | Local | Global |
|---|---|---|
| Question | Why **this one** prediction? | What does the model rely on **overall**? |
| How | SHAP values for one row | Aggregate SHAP values over many rows (average importance) |

## 3) The four axioms (the "fair rules")
The lecturer's taxi story: three people share a **$30** ride.

### Axiom 1: Efficiency
**Rule:** all contributions **sum to the total.** Feature SHAP
values sum to (prediction - average prediction).
**Taxi:** 10 + 12 + 8 = 30.
**Check (my run):** over 100 lab rows, sum of SHAP values +
base value matched the model's probability to within ~5e-8.

### Axiom 2: Symmetry
**Rule:** two features that contribute equally in every
situation get **equal** values.
**Taxi:** A and B ride the same distance -> **$15 each.**

### Axiom 3: Null (a.k.a. dummy)
**Rule:** a feature with **no impact** gets **zero.**
**Taxi:** C adds no distance or cost -> pays **$0.**

### Axiom 4: Additivity (linearity)
**Rule:** if you combine two models, SHAP values of the combo
= **sum** of the individual SHAP values.
**Taxi:** A's ride $10 + B's ride $20 = $30; each still owes
their own part.

**Hook:** **E**very cent counted, **S**ame work same pay,
**N**o work no pay, **A**dds up across rides. (**ESNA**.)

**Why they matter:** **fairness** (no feature unfairly favored)
and **transparency** (we can trust how the prediction is
split).

## 4) The formula (read it in plain words)
For feature **i**, SHAP value = **weighted average of its
marginal contribution over all subsets of the other features.**

Pieces (lecturer's names):
- **phi_i(f)** = SHAP value for feature i
- **N** = set of all features
- **S** = a subset of the features **not including i**
- **f(S)** = prediction using only features in S
- **f(S ∪ i)** = prediction when i is added to S
- **Marginal contribution** = f(S ∪ i) - f(S)
- **Weight** = depends on subset size, so it's fair

My addition (the weight, not spoken): 
phi_i = sum over S of  |S|! (|N|-|S|-1)! / |N|!  x [f(S∪i) - f(S)]

### Worked example (my addition, verified in python)
Two features A and B. Model payouts:
f(none)=0, f(A)=10, f(B)=20, f(A and B)=40.

**Feature A**
- Added first (to empty): 10 - 0 = **10**
- Added after B: 40 - 20 = **20**
- Average of the two orders: (10 + 20) / 2 = **15**

**Feature B**
- Added first: 20 - 0 = **20**
- Added after A: 40 - 10 = **30**
- Average: (20 + 30) / 2 = **25**

**Efficiency check:** 15 + 25 = **40** = f(A,B) - f(none). ✔
Teamwork bonus (40 vs 10+20=30) is split by the averaging.

**Trap:** SHAP is **order-averaged.** One order is unfair; the
average over all orders is fair.

## 5) Limitations (4)
1. **Computational cost:** compute grows **exponentially** with
   features (my addition: 2^n subsets: 12 features = 4,096,
   30 features = about 1 billion). Slow on big data or many
   predictions.
2. **Global interpretability is weaker:** designed for local;
   summary and beeswarm plots help, but not "inherently
   designed" to explain overall behavior.
3. **Feature independence assumption:** real features are often
   **correlated**, so SHAP can mislead.
4. **Doesn't correct bias:** it can **show** race or gender is
   influential but gives no way to fix it.
   **"Transparency does not equal fairness."**

## 6) What to do when you find bias (5 strategies)
1. **Bias audits and fairness checks** on sensitive attributes;
   metrics: **demographic parity, equal opportunity, disparate
   impact ratio.**
2. **Ethical data collection:** representative data, free of
   historical or societal bias (biased data -> biased
   predictions even with a transparent model).
3. **Post-processing:** adjust predictions after training (e.g.
   enforce demographic parity) without retraining everything.
4. **Human oversight / human-in-the-loop** in high-stakes areas.
5. **Fairness constraints in training:** optimize for accuracy
   **and** fairness across groups.

## Big picture recap
- SHAP = feature credit scoreboard from Shapley values.
- Four axioms keep it fair; **efficiency** = the totals add up.
- Local (one prediction) + global (average over many).
- Limits: slow, local-first, correlated features, **no bias fix.**
- Bias fix = audits, better data, post-processing, humans,
  fairness constraints.

## Definitions
- **Model interpretability:** "how much or how human can
  understand the cause of a decision or prediction made by a
  machine learning model." *(transcript garbled; read as "the
  degree to which a human can understand...")*
- **Fairness:** models "not biased and don't unfairly
  discriminate against individuals or groups based on sensitive
  attributes", e.g. race, gender, socioeconomic status.
- **Accountability:** enables developers, regulators, users to
  hold AI systems responsible for decisions; critical in high
  stakes areas such as criminal justice or healthcare.
- **Transparency:** making the model's decision-making process
  clear so users and developers can trust and understand the
  system and its logic.
- **SHAP:** Python library to explain output of ML models;
  based on **Shapley values** from **game theory**; each
  feature is a player; considers all possible combinations of
  feature values.
- **Model-agnostic:** applies to any model: linear regression,
  logistic regression, decision tree, neural network, etc.
- **Local interpretability:** why the model made a specific
  prediction for a particular instance.
- **Global interpretability:** aggregate SHAP values across
  many predictions; overall behavior; which features most
  important on average.

## Four axioms (names as lecturer gave them)
| Axiom | Rule | Taxi example |
|---|---|---|
| Efficiency | SHAP values sum to (actual prediction - average prediction) | $30 ride; contributions 10, 12, 8 = 30 |
| Symmetry | equal contribution in all situations -> equal value | A and B equal distance -> $15 each of $30 |
| Null / dummy | no impact -> SHAP value 0 | Person C adds no distance/cost -> $0 |
| Additivity / linearity | combined model's SHAP = sum of individual models' SHAP | A $10 ride + B $20 ride = $30 total, stay $10 and $20 |

## Formula, as the lecturer described it
- phi sub i of f = SHAP value for feature i.
- S ⊆ N \ {i}: all subsets of features **not including i**.
- N = set of all features.
- f(S) = prediction using only features in S.
- f(S ∪ i) = prediction when feature i is added to S.
- Marginal contribution = f(S ∪ i) - f(S) = how much adding i
  changes the prediction.
- Weighted average across all possible subsets S; the weight
  accounts for how large or small S is -> fairness.
- Derived from Shapley values in cooperative game theory.
- Considers all coalitions where feature i participates.

## Limitations (lecturer's order)
1. Computational complexity (grows exponentially with number of
   features; slow for large data or many predictions).
2. Global interpretability (primarily local; offers summary and
   beeswarm plots; not inherently designed for overall behavior).
3. Dependency on feature independence (correlated features
   -> misleading interpretations).
4. Doesn't correct bias ("Transparency does not equal fairness";
   fixing needs retraining, changing data, or fairness
   constraints).

## Mitigation strategies (lecturer's order)
1. Bias audits and fairness checks (fairness metrics:
   demographic parity, equal opportunity, disparate impact
   ratio)
2. Ethical data collection
3. Post-processing techniques (e.g., enforcing demographic
   parity; no full retraining)
4. Human oversight (healthcare, criminal justice; human-in-the-
   loop; ethical standards and societal laws)
5. Fairness constraints in model training (accuracy **and**
   fairness across demographic groups)
